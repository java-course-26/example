# Название проекта

Краткое описание проекта.
Здесь можно написать 2-3 предложения о том, что делает программа и для чего она нужна.

## Возможности

- Первая ключевая функция
- Вторая ключевая функция
- Третья ключевая функция
- Четвертая ключевая функция

## Требования

- JDK 17 или выше
- Любой текстовый редактор или IDE

## Установка

Склонируйте репозиторий:

    git clone https://github.com/user/example.git

## Сборка

Скомпилируйте исходный код:

    javac -d out src/main/java/*.java

## Запуск

Запустите программу:

    java -cp out Main

## Тесты

Скомпилируйте и запустите тесты:

    javac -d out src/test/java/*.java
    java -cp out TestMain
