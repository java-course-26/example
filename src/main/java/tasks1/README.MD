Для каждого предложенного варианта кода выполните следующие шаги:
    - Найти: Прочитайте код и найдите минимум 3 проблемы (ошибки, дублирование, плохая читаемость).
    - Объяснить: Оставьте комментарий в реквесте и кратко сформулируйте, почему это проблема.
               
                 Чек-лист для проверки
                    1. Корректность работы (Работает ли это на самом деле?)
                    2. Читаемость и простота (Поймет ли это другой человек?)
                    3. Структура и архитектура (Можно ли это улучшить?)

    - Исправить: Создйте свою ветку (ветвясь от tasks1), внесите предложенные вами изменения и
                 залейте их в вашу ветку. Создайте pull request в main.

                  # 1. Убедитесь, что вы находитесь на базовой ветке и у вас свежие изменения
                  git switch tasks1
                  git pull

                  # 2. Создайте новую ветку для своих исправлений и переключитесь на нее
                  git switch -c your_branch_name

                  # ... СДЕЛАЙТЕ ИЗМЕНЕНИЯ В КОДЕ В ВАШЕЙ IDE ...

                  # 3. Проверьте статус изменений (опционально, но полезно)
                  git status

                  # 4. Добавьте измененные файлы в индекс 
                  # (или укажите конкретный файл, например: git add src/main/java/...)
                  git add .

                  # 5. Создайте коммит с понятным сообщением
                  git commit -m "Сообщение сос мыслом"

                  # 6. Отправьте вашу ветку в удаленный репозиторий
                  git push --set-upstream origin your_branch_name
